## 보는 방법

```
git log --oneline              # 커밋 목록
git show <커밋>                 # 그 커밋에서 바뀐 줄 (+ 는 추가, - 는 삭제)
git show <커밋> -- <파일>        # 한 파일만
git show <커밋>:<파일>          # 그 커밋 시점의 파일 전체 (새 파일은 이걸 보고 통째로 친다)
```

- **새 파일**은 `git show <커밋>:<파일>` 로 전체를 보고 친다.
- **바뀐 파일**은 `git show <커밋> -- <파일>` 로 바뀐 줄만 보고 고친다.
- 주석(`/* */`, `//`)은 동작에 영향이 없다. 시간이 없으면 건너뛰어도 된다. 다만 `<?php` 와 `declare`, `namespace`, `use` 줄은 꼭 친다.
