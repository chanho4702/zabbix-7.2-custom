# 페이지별 완성도 (2026-11-24)

모듈 전체를 Codex 로 한 번 더 검수했다. 화면별로 Codex 점수와 우리 판단 점수를 함께 적었다.
두 점수의 기준이 다르다.

- **Codex 점수**: 코드만 보고 매긴 운영 준비도다. 5버전과 똑같이 만든 동작(5버전도 그랬던 것)도 감점했다.
- **우리 점수**: 5버전을 기준으로 매겼다. 5버전 화면을 얼마나 똑같이 옮겼는지, 그리고 고객 서버에서 남은 일이 얼마나 되는지를 본다.

## Codex 지적 처리

### 고친 것

| 지적 | 처리 |
|---|---|
| SW 인벤토리: 키가 20자(상태 표의 칸)를 넘는 줄은 입력 링크가 나오지만 저장이 실패한다 | 원인은 7버전에서 덧붙인 "ITSM ID 가 없으면 호스트명을 키로" 였다. 5버전대로 키를 `itsm_` + ITSM ID 로만 만들고, ID 가 비었거나 20자를 넘는 줄은 링크를 만들지 않는다. `includes/SwInventoryService.php` |
| 결과 저장 폴더(`/tmp/dmove_cache`)를 다른 사용자가 먼저 만들어 두면 저장 결과를 바꿔치기할 수 있다 | 바로가기(심볼릭 링크)이거나 웹 서버 사용자가 만든 폴더가 아니면 쓰지 않는다. `includes/UsageCache.php` |
| 결과 저장: 오래된 파일을 읽을 때 지우지 않는다 | 읽을 때도 지운다 |
| CPU/Memory 추출: 기간이 원본 값 보관 기간보다 길면 앞부분이 조용히 빠진다 | 저사용/고사용처럼 화면에 노란 안내 상자를 띄운다. 파일은 그대로 받을 수 있다 |

### 5버전과 같아서 그대로 둔 것

| 지적 | 이유 |
|---|---|
| SW 인벤토리가 권한과 관계없이 모든 호스트를 DB 에서 직접 읽는다 (Codex: HIGH) | 5버전이 그랬고, "전체 서버를 보는 게 맞다"고 정했다 (2026-11-24). 메뉴 권한이 있는 사람만 화면을 연다 |
| 사용 안 함 상태의 호스트/아이템도 저사용, 고사용, 일일점검, 패치 집계에 들어간다 | 5버전 사용률 집계(`...CPU`, `...Lowserver`)에도 상태 조건이 없었다. 일일점검, 패치는 5버전 소스와 대조할 때 같이 본다 |
| CPU 아이템이 둘 이상인 서버는 평균이 큰 아이템 하나의 평균과 Peak 를 쓴다 | 5버전 판단 근거가 불분명해 그대로 뒀다 (`미구현_목록.md` 8장 9번) |
| 저사용 기준값이 고사용 기준값보다 커도 저장된다 | 5버전 [기준설정] 창도 칸마다 1~99 만 검사했다 (`popup.lowserver.php`) |
| Agent 저장이 ITSM 에 실제 있는 키인지 확인하지 않는다 | 받은 5버전 소스에도 확인하는 부분이 없다 (파일 앞부분 15줄은 못 받음). 저장되는 것은 상태 기록뿐이다 |
| Peak: 트리거가 여러 호스트에 걸리면 첫 호스트만 보인다 | 5버전도 같다 (`peak_event.php` 의 `$trigger['hosts'][0]`) |

### 알고만 있을 것 (지금 규모에서는 문제 될 가능성이 낮다)

| 지적 | 메모 |
|---|---|
| 일반 CSV/Excel 내보내기는 전체 결과를 메모리에 만든다 | 서버 수천 대 규모는 괜찮다. 사용률 추출만 흘려보내기 방식이다 |
| 윈도우즈 패치: HotFix 필터를 쓰면 호스트마다 한 번씩 조회한다 | 호스트가 아주 많으면 느릴 수 있다 |
| 서머타임이 있는 시간대에서는 업무시간 경계가 한 시간 어긋날 수 있다 | 한국은 서머타임이 없다 |
| zip 이 4GB 를 넘으면 깨진다 | 줄 수 한도(1000만 줄)로는 넘지 않는다 |
| 사용률 추출은 줄 수를 수집 간격으로 어림하므로 실제보다 적게 잡히면 한도를 넘을 수 있다 | 넘으면 파일 끝에 "불완전" 줄이 들어간다 |
| 보관 기간 안내는 설정값 기준이다. 정리 작업이 늦거나 DB 에서 따로 지운 것은 모른다 | 그래서 "지워졌을 수 있다"고만 안내한다 |

## 확인 방법

- Codex 는 읽기 전용으로 돌렸다. 5버전 원본 폴더는 열지 않게 했다.
- 고친 것은 테스트 서버(Zabbix 7.0)에서 확인했다.
  - 사용률 추출을 2025-06 으로 조회하면 안내가 뜨고, 2026-11 로 조회하면 뜨지 않는다.
  - SW 인벤토리의 입력 링크는 그대로 나온다.
  - 저사용 결과 파일은 그대로 저장된다 (폴더 주인 zabbix, 0700).
